# Petri Malmström — Portfolio

Personal portfolio single-page app built with **Vite + React**.

WebGL hero shader, interactive skill constellation, animated TDD terminal, scroll-driven timeline and FI/EN language switch.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs static site to dist/
```

Content (texts in Finnish and English, contact details) lives in `src/i18n.jsx`.
